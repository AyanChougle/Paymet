# Payment Portal — HTML/CSS/JS + Hostinger MySQL

## Stack
Frontend: HTML, CSS, vanilla JavaScript.
Backend: PHP 8+ API.
Database: MySQL/MariaDB on Hostinger.

## Install
1. Create a Hostinger MySQL database/user.
2. Import `sql/schema.sql` in phpMyAdmin.
3. Copy `config.example.php` to `config.php` and enter DB credentials.
4. Upload all files to `public_html/payment-portal/` (or your chosen folder).
5. Create the first ADMIN user with a one-time PHP script or insert a password hash generated by PHP `password_hash()`.
6. Delete any setup script after use.

## API
The frontend calls `api.php` using fetch(). PHP sessions provide authentication.
No Node.js is required.

## Workbook mapping
Payment Entry maps the live October payment columns. INR is calculated as USDT × Divided By. Dashboard and Summary Reports query MySQL directly, so no Excel formulas/pivots are required.
